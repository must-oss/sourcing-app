크롬 확장 설치 안내

도매몰 검색과 이미지 다운로드를 쓰려면 크롬 확장 프로그램을 한 번만 설치하면 됩니다. 5분이면 끝납니다.

왜 확장이 필요한가요?
도매몰 상품은 사업자 승인 로그인을 해야 보입니다. 이 확장은 회원님이 이미 로그인해 둔 크롬 브라우저를 그대로 사용해서 상품을 찾아옵니다. 그래서 도매몰 아이디·비밀번호를 저장하지도, 서버로 보내지도 않습니다.

0단계 · 파일 받기

⬇ 확장 프로그램 다운로드 (zip)

받은 zip을 반드시 압축 해제하세요. 압축 상태로는 설치할 수 없습니다.
압축 푼 폴더는 지우지 말고 그대로 두세요. 크롬이 그 폴더를 계속 참조합니다. (예: 바탕화면\소싱도우미확장)

설치 (최초 1회)

  1. 크롬 주소창에 chrome://extensions 를 입력하고 Enter
  2. 화면 오른쪽 위의 "개발자 모드" 스위치를 켭니다
  3. 왼쪽 위에 새로 생긴 "압축해제된 확장 프로그램을 로드합니다" 버튼 클릭
  4. 0단계에서 압축을 푼 폴더를 선택합니다
    폴더 안에 manifest.json 파일이 보이는 위치를 선택해야 합니다
  5. 목록에 "소싱 도우미 (도매몰 검색)" 카드가 나타나면 설치 완료 ✅

사용법

  1. 이용할 도매몰에 먼저 로그인하세요. (사업자 승인된 계정)
    로그인 안 된 도매몰은 결과가 0건으로 나옵니다
  2. 소싱 웹앱 → 도매몰 소싱 탭 → 키워드 입력 → 도매몰 선택 → 검색
  3. 숨김 탭이 잠깐 열렸다 닫히면서 가격 낮은 순으로 결과가 표시됩니다
  4. 원하는 상품의 📥 버튼을 누르면 저장 폴더명을 물어보고,
    다운로드 폴더 안에 썸네일(1) + 상세 이미지(s1, s2 …) 가 한 번에 저장됩니다
⚠️ 처음 다운로드할 때 크롬이 "여러 파일을 다운로드하시겠습니까?" 를 물어봅니다 → 허용을 눌러주세요. 거부하면 이미지가 1장만 저장됩니다.

자주 겪는 문제

"크롬 확장이 연결되지 않았습니다" 라고 나옵니다

확장을 설치한 직후에는 웹앱 페이지를 새로고침해야 연결됩니다. Ctrl + F5 를 눌러주세요.
그래도 안 되면 chrome://extensions 에서 "소싱 도우미" 카드의 🔄 새로고침 아이콘을 누른 뒤 다시 Ctrl+F5 하세요.

검색 결과가 0건으로 나옵니다

대부분 해당 도매몰에 로그인이 안 된 상태입니다. 도매몰을 새 탭에서 열어 로그인 상태인지 확인하고 다시 검색하세요.
도매몰은 사업자 승인이 완료된 계정이어야 상품이 보입니다.

"개발자 모드 확장 프로그램을 사용 중지했습니다" 경고가 뜹니다

크롬이 개발자 모드 확장에 대해 종종 띄우는 안내입니다. "취소" 를 누르면 계속 사용할 수 있습니다. ("사용 중지"를 누르면 꺼지니, 그때는 chrome://extensions 에서 다시 켜주세요.)

크롬을 재시작하면 확장이 사라집니다

압축 푼 폴더를 옮기거나 삭제하면 확장이 사라집니다. 폴더를 원래 자리에 두고, 필요하면 설치 단계를 다시 진행하세요.

이미지가 엉뚱한 게 저장됩니다

도매몰이 사이트 구조를 바꾸면 생길 수 있습니다. 어느 도매몰, 어느 상품에서 그런지 알려주시면 맞춰 수정합니다.

안심하셔도 되는 부분
· 도매몰 비밀번호를 묻지 않고 저장하지 않습니다 — 이미 로그인된 브라우저만 사용합니다
· 확장이 접근하는 사이트는 위 표의 4개 도매몰과 이 웹앱뿐입니다 (다른 사이트는 접근 권한 자체가 없습니다)
· 수집한 상품 정보는 회원님 브라우저 안에서만 처리되며 서버로 전송되지 않습니다
